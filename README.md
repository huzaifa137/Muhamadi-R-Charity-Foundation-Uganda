# Muhamadi R Charity Foundation Uganda — Premium Static Website

## Structure
- HTML5 pages: Home, About, What We Do, Our Impact, Stories, Gallery, Get Involved, Contact
- CSS: `css/style.css`
- JavaScript: `js/main.js`
- Gallery data: `js/gallery-data.js`
- Images: `assets/images/`
- Gallery: `assets/images/gallery/`

## Form
The contact form validates in the browser but does not pretend to send email. Connect it to a backend, Formspree, Netlify Forms, Laravel endpoint, etc.

## Gallery
The gallery uses all 101 supplied photographs in optimized WebP format and opens images in a keyboard-friendly lightbox.

## Run locally
Open `index.html` in a browser. For best behavior, serve the folder with any simple local static server.
